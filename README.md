# Los Angeles Sign Company — Homepage Redesign Mockup

Static homepage mockup for client review. **Not the live site.**

- Live site: https://losangelesigncompany.com
- Direction: Evelio's reference sites (Impact Signs, Woodland Manufacturing, Alphabet Signs, American Sign Letters, Letters and Signs) — easy product selection, customize material/size/finish, see pricing, pay online, separate installation quote.
- Prepared by Makarios Marketing, October 2026

## What this is

A single static page (`index.html` plus `img/` and `fonts/`). No build step, no dependencies.
Open `index.html` locally, or view the Vercel deployment.

## Working demo pieces

- **Shop Signs mega menu** and category filters (All / Sign Letters / Lighted / Interior / Exterior)
- **Build & price configurator**: text, letter style, material, finish, height, depth, halo lighting, mounting, with a live preview and running price
- **Cart drawer** with secure-checkout button (placeholder) and installation-quote add-on
- **Installation quote form** (address, sign type, surface, height, photos)
- Quote form and mobile menu

## Placeholders to confirm with the client

- All prices and pricing rules are samples for layout.
- Checkout button and forms do not submit anywhere yet.
- `info@losangelesigncompany.com` email address, pickup/delivery options, payment methods.
- Service-area map is a stylized panel; a live Google Map embeds at launch.
- All photos are the client's own project photos from losangelesigncompany.com.

Marked `noindex, nofollow` (meta tag + Vercel header) so it cannot appear in search results.
